# PlayLog 小程序

原生微信小程序 + TypeScript 的 MVP 原型，当前阶段先完成产品骨架和静态 UI。

## 打开方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前工作区下的 `PlayLog/` 文件夹。
4. AppID 可以先使用测试号，正式开发前再替换 `project.config.json` 里的 `appid`。

## 当前页面

- 今日：游玩记录、最近在玩、今日碎片、分享入口。
- 游戏库：游戏状态、平台、进度和标签。
- 收藏柜：盲盒、文具、周边的收藏展示。
- 我的：主题、模板、备份、导出等入口。

## 后续开发建议

- 接入微信云开发，用云数据库替换 `miniprogram/utils/mock.ts`。
- 图片上传接云存储，数据库只保存 fileID 和元数据。
- 分享图建议先从“今日碎片”和“月度报告”两类模板开始。
