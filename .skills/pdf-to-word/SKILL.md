# PDF 转 Word 转换器

一个将 PDF 文件转换为 Word 文档（.docx 格式）的 skill，尽可能保留格式、布局和内容结构。

## 使用场景

当用户有以下需求时使用此 skill：
- 明确要求将 PDF 转换为 Word/docx
- 想要使 PDF 可编辑
- 需要从 PDF 中提取内容到 Word 文档
- 询问 PDF 到文档的转换

## 工作原理

此 skill 使用 Python 库来：
1. 从 PDF 中提取文本和布局信息
2. 保留格式（标题、段落、列表、表格等）
3. 生成格式正确的 .docx 文件

## 使用说明

### 第一步：定位 PDF 文件

如果用户没有提供 PDF 文件路径，请询问用户。如有需要，可以搜索常见位置：
- 下载文件夹
- 桌面
- 当前工作目录

### 第二步：运行转换

使用打包的转换脚本：

```bash
python scripts/convert_pdf_to_word.py <输入PDF路径> <输出docx路径>
```

如果未指定输出路径，则使用与输入 PDF 相同的文件名，扩展名改为 `.docx`，保存在同一目录下。

### 第三步：验证并交付

1. 确认转换成功完成
2. 向用户报告输出文件的位置
3. 可选择为用户打开文件进行查看

## 支持的功能

- 文本提取并保留段落结构
- 基本标题检测
- 列表检测（项目符号和编号）
- 表格提取（在结构可检测的情况下）
- 图片提取（嵌入到 Word 文档中）

## 局限性

- 复杂的布局可能无法完美保留
- 某些字体可能不完全匹配
- 矢量图形可能会转换为图片
- 有密码保护的 PDF 需要提供密码

## 故障排除

如果转换失败：
1. 检查 PDF 是否有密码保护 - 向用户询问密码
2. 验证 PDF 文件是否损坏
3. 检查是否安装了所需的 Python 包：
   - `pdfplumber` 或 `PyMuPDF` (fitz) 用于读取 PDF
   - `python-docx` 用于创建 Word 文档
   - `Pillow` 用于图片处理

安装缺失的包：
```bash
pip install pdfplumber python-docx Pillow
```

## 输出格式

此 skill 生成一个 `.docx` 文件，包含：
- 保留的文档结构
- 可读的文本内容
- 基本格式（粗体、斜体、标题）
- 适用的嵌入图片
